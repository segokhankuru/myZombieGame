# Editor Tools Rules

**Scope:** `Assets/_Project/Code/Editor/**` (assembly `Game.Editor`, Editor platform only)

This is the only code allowed to author Unity assets. Everything here exists so that
nobody hand-edits YAML.

## Assembly
- Editor asmdef, Editor platform only. Editor code reachable from a runtime assembly
  breaks the player build, always at the worst moment.
- No gameplay logic here. A tool that decides a game rule has put the rule in the wrong
  place.

## Idempotent and deterministic
- **Running a tool twice produces the same result as running it once.** Authoring tools
  that append are how a scene ends up with forty duplicate lights.
- Same input, same output, same GUIDs where possible. That is what makes generated
  content diffable.
- Re-running must not dirty a file that is already correct.

## Bulk operations
- `AssetDatabase.StartAssetEditing()` / `StopAssetEditing()` around bulk work, in a
  `try/finally`. Without it a 500-asset import takes minutes instead of seconds.
- One `SaveAssets` at the end, not per asset.
- `AssetDatabase.Refresh()` only when genuinely needed.

## Undo
- `Undo.RecordObject` / `Undo.RegisterCreatedObjectUndo` on anything touching an open
  scene. A tool that cannot be undone will eventually eat someone's afternoon.
- Mark scenes dirty explicitly: `EditorSceneManager.MarkSceneDirty`.

## Failure messages
- Fail loudly with the fix in the message:
  `Config key 'payout.base' missing - add it to config/schema/economy.schema.json`
  beats a null reference every time.
- Validate inputs before starting bulk work, not halfway through.

## Command line
- Anything CI will need is a `static` method callable via `-executeMethod`, reading
  arguments from the command line and exiting non-zero on failure.
- It must not depend on any Editor window being open.

## The config importer specifically
- `config/schema/*.json` generates the C# class, marked `// <auto-generated>`.
- `config/balance/*.json` fills the `.asset` instance.
- Unknown key: **error**, not warning. The schema is the contract.
- Missing required key: error naming the schema path.
- Schema ranges become `[Range]` attributes so the Inspector shows design intent.
- The importer is the only writer of `Assets/_Project/Config/*.asset`.

## Forbidden
- Modifying `.meta` files directly - use the importer API
- Generating content a designer should be authoring
- A tool that only works with a specific scene open, without saying so in its message
